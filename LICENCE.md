## ✨ Features

### 🎮 Core Overlay
- ESP — highlight players through walls with boxes and names
- Radar Overlay — mini-map showing nearby player positions
- Aim Assist Overlay — soft aim guide overlay for tracking
- Skeleton ESP — draw player bone lines
- Distance Indicator — show range to each target

### 🎨 HUD & Interface
- HUD Toggles — enable or hide overlay elements on screen
- Config Presets — save and load overlay layouts
- Color Themes — customize ESP and radar colors
- Hotkey Binds — assign per-feature toggles

### 🏋️ Training & Utility
- Recoil Guide — visual recoil pattern overlay
- FPS Counter — monitor performance while overlay is active
- Stream-Proof Mode — hide overlay from capture software
- Instant Toggle — quick enable or disable of all features
